## Goal

Opening a `.ts`, `.tsx`, `.js`, `.jsx`, `.mjs`, `.cjs`, `.html`, `.css`, `.scss`, `.less`, `.json` or `.jsonc` file gives the editor what a C# file has today: tree-sitter highlighting at once, then the language server's completion, hover, signature help, go to definition, find all references, rename, code actions, diagnostics, formatting, semantic tokens and inlay hints as they arrive, through the generic server path of brief 0019 and `servers.json` entries, with no per-language code in the shell. The servers are located on the machine or fetched pinned by `tools/web-servers/fetch.sh` into the cache (never vendored, never at startup): `typescript-language-server` over the project's own TypeScript (`node_modules/typescript` first, the pinned one as the fallback), `vscode-langservers-extracted`'s HTML, CSS and JSON servers (the services extracted from VS Code, MIT), ESLint's language server (`vscode-eslint`'s server, MIT) when the project has an ESLint configuration, and Prettier or Biome for Format Document when the project has one configured (the format command runs the project's own formatter, else the language server's `textDocument/formatting`). Emmet abbreviations expand on Tab in HTML and CSS through the `@vscode/emmet-helper` package served by the HTML server's completion where it offers it, else a small expander for the common forms in the shell. Razor (`.cshtml`, `.razor`) is out of scope here (its own brief), but a `.cshtml` file gets HTML highlighting and the HTML server's completion in its markup regions so the WebForms and MVC corpus is not blank. Everything also works for the Vite project's TypeScript through `tsconfig.json` and for an ASP.NET project's `wwwroot` without one, and the existing commands (`eludite.editor.*`) cover it for agents with nothing new to learn.

## Contract

- **Highlighting first.** A supported file is highlighted by tree-sitter within the editor's existing budget before any server answers; the server's semantic tokens layer over it as C# does today.
- **Servers.** Each is a `servers.json` entry; a document with several servers gets the fan-out and merge rules above; a server that is not found shows the status bar's "not found" state with the fetch command and nothing else degrades; a server that crashes restarts as brief 0019's generic server does with its documents replayed; nothing is launched at startup, only when the first matching document opens.
- **TypeScript.** The project's own TypeScript version is used when present (reported in the status bar's tooltip), the pinned one otherwise; `tsconfig.json` and `jsconfig.json` are honored by the server; JavaScript files get the same features with `checkJs` as the project says.
- **ESLint.** On when `languageServers.eslint` is `auto` and a configuration file exists (flat config `eslint.config.*` or legacy `.eslintrc.*`), always with `on`, never with `off`; its diagnostics carry the rule id and a fix action; "Fix all ESLint problems" is a code action and a command through the existing `eludite.editor.apply_code_action`.
- **Formatting.** Format Document (Ctrl+K, Ctrl+D) runs the project's Prettier (`prettier` in `node_modules`, with the project's configuration) or Biome (`biome.json` present) as the setting says, else the language server's formatting; format on save per language; the result applies through the workspace-edit applier as one undo step; a formatter that fails writes an Output line and leaves the document.
- **JSON schemas.** The pinned SchemaStore catalog subset (the files named above) gives completion and validation in those files; no network for schemas (the subset is cached by the fetch tool).
- **Emmet.** Tab expands a recognized abbreviation in HTML and CSS when no completion item is selected; Escape leaves it.
- **Agents.** Nothing new: `eludite.editor.*` works on these files; the report shows an agent fixing a type error and an ESLint violation through `diagnostics.list`, `code_actions` and `apply_code_action`.
- The UI thread never waits on a server or a formatter; every request carries the generation; no network at startup; `node` runs only for a server or a formatter the person or an agent invoked.
- Commit messages: one plain, direct, active-voice line each; no body, no trailers.

## Budget

- Highlighting: within the editor's existing keystroke budget (8 ms p99 to frame) on a 10,000-line TypeScript file.
- First completion from `typescript-language-server` on the Vite project under 1.5 s cold (the server's startup), under 100 ms p95 warm; ESLint diagnostics within 2 s of a save on the fixture.
- Format Document on a 2,000-line file under 500 ms with Prettier warm.
- Dependencies: the tree-sitter grammars (MIT) in `crates/editor`; the Node packages are located tools, pinned in `tools/web-servers/PIN` with their SPDX ids (all MIT except `@biomejs/biome`, MIT, and `prettier`, MIT); no other new Rust crate.
