## Goal

Double-click a `.resx` file in the Workspace window, or open it with `eludite.file.open`, and the tab titled by the
set's neutral file opens with the grid: a row per key, the Key and Comment columns, one column per culture with the
neutral culture first and labeled by the project's neutral language, cells edited in place (an edit in an empty
culture cell creates the entry on the fly), a missing cell tinted, a cell with a consistency warning carrying a
glyph and its message in the status line, an invariant key (`{Invariant}` in its neutral comment) dimmed in the
culture columns. The toolbar has Add Key, Delete, Rename (F2), Invariant, the Missing, Warnings and Invariant
filters, the search box over keys, values and comments, the Access Modifier list (Internal, Public, No code
generation) that edits the project through the host and regenerates or deletes `Name.Designer.cs`, and Save. The
tab is dirty until Save (Ctrl+S), which writes every dirty file through the workspace-edit applier keeping every
untouched byte, the byte order mark and the line endings, and has the host regenerate the designer when keys were
added, removed or renamed; closing a dirty tab asks. Non-string entries sit read-only under Other Resources. Open
With > XML (Text) Editor and the setting `resx.openAsText` give the text editor. Agents read and write the same sets
through `eludite.resx.sets`, `entries`, `validate` (read), `set`, `add`, `rename`, `access_modifier` (edit_buffer:
an agent's write is held as pending changes under `edit_buffer: review`) and `remove` (edit_buffer under the policy's
`resx.remove`, `prompt` by default). The host lists the sets with their project knowledge (`eludite/resx/sets`) and
writes the designer in `ResXFileCodeGenerator`'s shape (`eludite/resx/designer`).

## Contract

- **The file model.** `eludite-resx` parses a file's string entries (no `type` and `mimetype`, or a `System.String`
  type) and lists the others; every edit is a splice that keeps every other byte, the byte order mark and the line
  endings; a new entry takes Visual Studio's shape at the end of the file; a removed one takes its line; a renamed
  one changes the `name` attribute; `Name.<suffix>.resx` is a culture file only when the suffix is in the generated
  culture table (`Default.aspx.resx` is neutral); UTF-16 files are refused with a message.
- **The editor.** One tab per set (`resx:<neutral file>`), titled by the neutral file, whichever file was opened;
  the files parsed off the UI thread; the grid virtualized; the rules as the settings say; dirty until Save, which
  writes through the applier and regenerates the designer when keys changed; closing a dirty tab asks.
- **The commands.** Reads come from the open editor's model or a fresh load off the UI thread; a write loads the
  set afresh, applies the operation and writes through the applier (an agent's under `edit_buffer: review` is held
  as pending changes and answered `pending`); an open editor with unsaved changes refuses a write from another
  caller; `remove` is dangerous for an agent under `resx.remove: prompt`; `access_modifier` is the host's
  `setModifier`; every write is audited with its arguments.
- **The host.** `eludite/resx/sets` lists every `EmbeddedResource` `.resx` not under `bin/` or `obj/` with the
  metadata `host-rpc.md` names; `eludite/resx/designer` reproduces `ResXFileCodeGenerator`'s and
  `PublicResXFileCodeGenerator`'s output for the corpus byte for byte, edits the project preserving formatting,
  and reloads the solution after a project write.
- The UI thread never waits on the files or the host; the host's stdout stays protocol-only; every host call
  carries the generation.
- Commit messages: one plain, direct, active-voice line each; no body, no trailers.

## Proving test

- `cargo test -p eludite-resx`: the unit tests and `tests/corpus.rs` (every corpus file round-trips byte for byte
  through every kind of splice; the sets, rows and warnings of `corpus/resx/README.md`).
- `cargo test -p eludite-commands`, `-p eludite-protocol`, `-p eludite-lsp --features fake`, `-p eludite-mcp`: the
  schemas, the policy object, the settings keys, the typed messages, the fake host, the tools and the guide.
- `cargo test -p eludite resx_tests` (headless, the fake host): the tests `crates/eludite/src/shell/resx_tests.rs`
  lists in its docs.
- `dotnet test dotnet/Eludite.slnx --filter "FullyQualifiedName~Resx"`: the host's sets, the three designers byte for
  byte, `setModifier`, the stale generation, the wire.

## Budget

- A 5,000-key set in 3 cultures shows its rows within 100 ms of the open (the files parsed off the UI thread).
- Keystroke to frame p99 under 8 ms while the selection moves through that grid (`assert_budget`).
- Cold start unchanged: nothing parses before a `.resx` opens. No new Rust dependency (`roxmltree` and `ignore` are
  in the build); no new .NET package.

## Exit criterion

1. `cargo fmt --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace` green;
   `dotnet build` zero warnings and `dotnet test` green with the Resx tests running on the corpus.
2. The report records the budget numbers, what the designer generator reproduces and where the corpus's expectation
   is a guess, what the agents' review hold does, and what R2 (languages, references, exchange) needs.
3. `CLAUDE.md`, `README.md` if touched, `corpus/README.md` and the briefs and proposals indexes match the repository.
