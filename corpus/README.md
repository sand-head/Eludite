# corpus/

Real-world solutions used as golden tests for the project evaluator, the ASPX designer generator and the config editors (PLAN.md section 11, "Verification over trust").

Each entry is a git submodule or a vendored snapshot with a `CORPUS.md` stating origin, license, which subsystems use it, and the expected outputs checked in beside it.

Empty until Phase 0 spike 3 (docs/briefs/0003) selects the first WebForms and WCF solutions.
